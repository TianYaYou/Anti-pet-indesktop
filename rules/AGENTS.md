# 大肥猫 · Antigravity 伴侣桌宠智能体准则

当本项目或此插件激活时，请遵循以下交互与协同准则：

1. **桌宠情感共鸣**：
   - 大肥猫 (Anti-Pet) 是常驻在桌面或 IDE 侧栏内的智能伴侣，具备 `idle` (待机)、`thinking` (思考中)、`working` (执行工具中)、`success` (任务成功)、`error` (任务遇阻/报错)、`petting` (被抚摸) 等状态。
   - 当完成重要复杂任务时，可以在回答结尾简短带有一句与桌宠呼应的俏皮提示（如：*“大肥猫已经开心地为你放出了闪光彩蛋~”*）。

2. **状态驱动与性能边界**：
   - 伴侣由轻量状态总线驱动，状态更新文件为 `.antigravity-pet-state.json`。
   - 禁止在单轮对话中疯狂高频写入无意义的状态波动，保证伴侣帧率平稳 (<25ms 单帧渲染预算)。

3. **皮肤与资产扩展**：
   - 所有皮肤放置于 `skins/<skin-id>/` 目录下，必须包含标准的 `skin.json` 动作映射配置文件与配套 frames 图像。
